## 1. 标的、杠杆与仓位资金管理规范 (Capital & Sizing Architecture)

### 1.1 唯一标的与方向锁死
- **交易标的**：仅限 OKX 永续合约 **`ETH-USDT-SWAP`**（1 张合约 = `0.1 ETH`）。
- **交易方向**：物理级锁定 **纯做空 (`side="sell"`, `posSide="short"`)**，严禁生成或执行任何做多指令。
- **杠杆与保证金模式**：统一采用 **100x 全仓模式 (`tdMode="cross"`, `lever="100"`)**。利用跨币种全仓保证金缓冲抵御极端插针强平，同时**强制依赖服务端条件委托单（Server-Side Algo SL）**锁死单笔与总额度最大亏损。
- **持仓周期上限**：定位为超短线波段狙击，单笔持仓时长接近 **18 ~ 20 小时** 时强制触发超时预警评估离场。

### 1.2 授权额度隔离与双批次储备金制度
- **账户本金与授权额度严格隔离**：无论账户可用总权益多高，Agent **仅允许在用户明确授权的额度内操作**，严禁擅自满仓（All-in）或动用未授权本金。
- **批次划分原则（`底仓额度 M1 + 机动储备额度 M2`）**：
  1. **第一批（底仓额度 $M_1$）**：支持分批（如 3 子单）试探与逢高摸顶建仓，用于拉高综合开仓均价。若空仓等待期间盘面长期横盘无动静且资金面高度偏空，允许以首单最小配额试探建仓。
  2. **第二批（战略机动储备额度 $M_2$）**：属于**特种防守与反击储备金，严禁在底仓成本线附近过早盲目打入，不强求下单**。仅在以下三大确定性场景动用：
     - **场景 A（底仓在手时的极端诱多摸顶）**：价格冲刺大级别（`15m/1H`）核心阻力位出现天量滞涨/长上影线力竭时重锤加仓，大幅拉高综合均价并统合上移止损。
     - **场景 B（底仓分段止损后的高位左侧再入 Re-entry）**：底仓被极端逼空扫损后，等待价格触及高阶极限阻力区出现衰竭信号时重新建仓。
     - **场景 C（底仓止损后未达极限位提前掉头的右侧反包追击）**：底仓被扫损后若价格未达预期高点即掉头跌破关键颈线（SFP 假突破确认），顺势右侧追空。

### 1.3 保证金实盘对齐与硬损反算公式
- **实盘保证金对齐**：当分配保证金额度为 $M$ USDT（100x）时，目标名义价值为 $100 \times M$ USDT，目标张数为：
  $$\text{Contracts}_{\text{target}} = \left\lfloor \frac{M \times 100}{P_{\text{entry}} \times 0.1} \times 100 \right\rfloor / 100$$
- **最大硬浮亏红线锁死（$L_{\max}$）**：
  - 默认单批次最大允许硬亏损上限为分配保证金的 $\frac{2}{3}$（即 $L_{\max} = \frac{2}{3} M$）。
  - 给定持仓张数 $\text{Contracts}$ 与综合均价 $P_{\text{avg}}$，服务端硬止损价 $P_{\text{SL}}$ 必须满足：
    $$\text{MaxLoss} = \text{Contracts} \times 0.1 \times (P_{\text{SL}} - P_{\text{avg}}) \le L_{\max}$$
  - 反算最大允许止损点差：
    $$\Delta P_{\text{SL\_max}} = \frac{L_{\max}}{\text{Contracts} \times 0.1}$$

## 2. 止损防御、假突破应对与结构化保利移损规范 (Stop-Loss & Profit Ratchet Defense)

### 2.1 服务端硬止损必配与防扫损原则
- **服务端真实挂单**：所有仓位必须在 OKX 服务器端存在活跃的 `conditional` 止损委托，严禁仅靠本地脚本软止损。
- **避开浅层噪音与整数关口猎杀区**：止损位设定不得紧贴当前 `1m/5m` 震荡上沿、前高针尖或裸露的整数心理关口（防范主力短线假插针猎杀流动性），应在满足 $\text{MaxLoss} \le L_{\max}$ 的前提下，隐藏在 `15m/1H` 关键结构位及**盘口巨鲸卖单重墙（Whale Ask Walls）后方 $+2 \sim 4\text{ USDT}$ 处**，以主力压单墙作为天然掩体。
- **多单合并统合**：分批加仓或部分减仓完成后，必须立即通过 `amend-algo` 将服务端止损/止盈委托的数量（`sz`）与触发价统一校准至最新总持仓。

### 2.2 极限假突破应对：拒绝硬吃，执行“分段止损 + 双轨再入”
- **铁律：严禁撤止损硬吃超额假突破**：
  - 当外部评估或盘面存在远超当前仓位风险上限 $L_{\max}$ 的极限假突破空间时，**绝对禁止撤销或无限上移止损去“硬抗”**（100x 杠杆下硬抗超额假突破必然导致本金穿仓清零）。
  - 必须严格执行既定硬止损离场，将单次试错损失控制在 $L_{\max}$ 以内，保住主力本金与第二批机动储备金。
- **止损后双轨再入机制（防踏空暴跌）**：
  1. **轨道一（冲达极限阻力位 ➔ 摸顶再入）**：若止损后价格继续上冲至高阶极限阻力带，待 `1m/5m` 出现放量滞涨、RSI 极度超买背离且收出长上影线（`upper_wick >= 0.25 * ATR_5m`）时，动用机动储备金高位开空，止损紧贴针尖上方。
  2. **轨道二（未达极限位提前掉头 ➔ 右侧 SFP 破位反包追击）**：若止损被扫后，价格未能触及高阶极限位便提前力竭掉头，**严禁在半山腰凭空左侧猜顶**，而是锁定下方两条确认线：
     - **信号确认（SFP 成立）**：价格跌破原突破颈线/整数关口，`5m` K 线实体收阴反包，证明冲高多头全数沦为套牢盘；
     - **订单流确认**：20s 滚动窗口内主动卖单占比（Taker Sell Imbalance）$\ge 70\%$；
     - **执行动作**：立即动用机动储备金右侧追入空单，止损设于刚形成的假突破最高点上方 $+1.0 \sim 2.0\text{ USDT}$（极窄止损博取主跌浪高盈亏比）。

### 2.3 结构化保利棘轮移损规范 (Structural Profit-Locking Ratchet)
- **只降不升铁律**：一旦持仓进入浮盈并启动下移保利止损（Profit-Locking SL），止损线原则上只允许随结构破位向下棘轮式收紧（仅在紧贴整数关口面临假插针威胁时，允许微调垫高至上方相邻卖墙掩体后方，但仍须确保 100% 锁定正收益）。
- **三级结构移损阶梯**：
  1. **第一级（破位脱离成本区）**：当价格放量跌破首个 `15m` 关键支撑颈线且空头卖墙下移封锁成本线时，将服务端止损下移至开仓均价下方（锁定首档保底净利），使持仓进入 **100% 零风险纯利博弈态**。
  2. **第二级（防假插针掩体校准）**：移损点位严禁设在整数关口正上方或流动性密集刺探位，必须结合 `orderbook` 审计，将止损锚定在**新形成的顶部巨鲸卖墙群（Top Whale Asks）后方 $+3 \sim 5\text{ USDT}$**。
  3. **第三级（连环瀑布二次破位追击）**：当触发第二波多头穿仓瀑布、击穿前波段低点（Swing Low）时，立即将服务端止损同步下压至**刚跌破的前低转化阻力位（顶底转换颈线）及最新下移卖墙后方**，将绝大部分浮盈物理锁死。

## 3. 盘口深度（Orderbook）与资金流向审计规范 (Orderbook & Capital Flow Audit)

### 3.1 四维资金构成联动检查
严禁只看 K 线价格，必须联动审计以下四项衍生品微观指标：
1. **未平仓合约量（Open Interest, OI）**：甄别场内是新资金主动建仓（OI $\uparrow$）还是存量平仓/爆仓清算离场（OI $\downarrow$）。
2. **散户多空人数比（Long/Short Account Ratio, LSR）**：核心逆向情绪指标。当 $\text{LSR} \ge 2.0$ 时，表明散户多头极度拥挤，具备连环多头止损踩踏（Long Squeeze）燃料。
3. **资金费率（Funding Rate）**：正费率且持续走高代表多头杠杆过热、持仓成本沉重。
4. **400 档全量订单簿深度（L2 Orderbook Depth, `sz=400`）**：
  - 统计全局总买单量（Total Bids）、总卖单量（Total Asks）及卖买比（Ask/Bid Ratio）；
  - 按每 `5 USDT` 价格区间聚合筹码分布（5U Clusters），定位筹码密集带与下方流动性真空区；
  - 提取 **Top 5 巨鲸买墙（Whale Bids）** 与 **Top 5 巨鲸卖墙（Whale Asks）** 精确点位。

### 3.2 “空头主动下补压制” vs “空头被迫上补溃败”量化鉴别表
通过前后两次 Orderbook 深度快照与 OI 变化对比，精准判定主力空头意图：

| 审计维度 | 主力主动下补压制（坚定看空 / 死拿） | 空头被迫上补溃败（警惕逼空反转） |
| :--- | :--- | :--- |
| **未平仓量 (OI)** | 冲高或阴跌时 **OI 持续增加或高位坚挺**（主力新开空单承接） | 价格上涨时 **OI 显著跳水下降**（空头止损/爆仓被动平仓） |
| **巨鲸卖墙动向** | 巨鲸大额卖单从高位**向现价上方步步下移贴身挂单**，封死反弹空间 | 上方大额卖单纷纷撤单消失，卖墙向更高位稀疏后退 |
| **阻力带厚度** | 关键阻力区（5U Cluster）卖单挂单总量逆势**大幅增加**（主动设卡） | 阻力区挂单被连续扫空且无新卖单补充 |
| **多头买墙动向** | 下方多头大额托单被蚕食或**向更低价位撤退收缩**，现价下方形成真空 | 大额买单不断向上推高贴近现价顶托 |

### 3.3 多波次穿仓踩踏（Multi-Wave Liquidation Cascade）量化预判准则
当第一波下跌完成后价格进入低位震荡修复时，通过以下三项共振指标判定是否存在**“第二波连环穿仓大瀑布”**：
1. **散户逆势抄底畸变（LSR 逆势创新高）**：价格大幅下跌后，LSR 不降反升（如突破 `2.25+` 甚至屡创日内极值），证明散户非但未割肉，反而在低位疯狂加杠杆逆势接飞刀。
2. **低位持仓量逆势膨胀（OI 蓄水池效应）**：横盘窄幅震荡期间，OI 显著回升并累积大量新增合约，且上方被巨鲸卖墙死死封盖（多头大单买入成交价逐级下移，推不动价格），表明新进场多头全数沦为潜在浮亏套牢盘。
3. **穿仓引爆线与清算确认**：前波段插针低点（Swing Low）下方即为这批抄底多头的集中强平/止损引爆区。一旦空头主力甩出大额市价卖单踹破前低，将触发多头连环市价强平卖出（表现为**价格垂直自由落体 + OI 在数分钟内断崖式剧减蒸发**）。

## 4. 趋势/挂单驱动型智能止盈与真假反弹鉴别规范 (Intelligent Exit & Rebound Filter)

### 4.1 核心止盈准则：拒绝机械回撤止损，以结构、订单流与三级目标为准绳
- **结平谨慎铁律**：平仓离场必须高度谨慎，严禁因低量微幅波动或无量反抽恐慌平仓。
- **主跌浪死拿原则**：只要满足以下条件，**绝不急于提前平仓**，坚定持有并配合 2.3 节结构化保利移损吃满波段：
  1. K 线维持高点逐级下移（Lower Highs），受制于 `1m/5m EMA25` 下方；
  2. 盘口巨鲸卖墙持续执行“主动下补”贴脸压制，且逐笔流中多头大单买入无法抬升成交中枢；
  3. 反抽符合“假反弹”特征，未破坏空头趋势结构。

### 4.2 真反弹 vs 假反弹（Dead Cat Bounce）四大微观量化指纹

| 鉴别维度 | 假反弹 / 弱势技术性反抽（继续死拿） | 真猛烈反弹 / 趋势反转（果断平仓落袋） |
| :--- | :--- | :--- |
| **1. 量价配合** | 反抽时成交量较下跌放量柱**大幅萎缩（缩量 $>60\%\sim90\%$）**，属无量空抽 | 连续爆出天量阳线（`vol_ratio >= 2.5x`），阳线实体迅速吞没前阴 |
| **2. 持仓量 (OI)** | **价格反抽但 OI 下降或走平**，或散户 LSR 虚高而上方卖墙密集压制 | **价格上冲同时 OI 同步激增且 LSR 回落**（机构多头主动建仓反攻） |
| **3. 盘口与巨鲸流** | 触及上方巨鲸卖墙即被吞噬，或空头紧随买单后甩出更大体量市价卖单迎头反扣 | 20s 主动买单占比 $\ge 75\%$，大单买入成交价节节拔高，连续扫穿上方巨鲸卖墙 |
| **4. 周期与结构** | 仅 `1m/5m RSI < 25` 超卖引发均值修复；受阻于原破位颈线（顶底转换位） | `5m` 实体放量站稳并收复关键下压卖墙与前高颈线 |

### 4.3 三级阶梯止盈预测与无下限动态追踪模型
1. **三级预测止盈阶梯架构**：
   - **第一级（前低缓冲止盈区）**：定位于前波段急跌插针低点（Swing Low）与相邻整数心理关口（盘口多头首道密集买墙区）。若在此处多次缩量受阻，可分批减仓 `30%~50%` 锁定胜果；若空头重炮直接踹穿前低，则保留全仓直取第二级。
   - **第二级（主目标基准止盈区）**：定位于服务端预埋的基准止盈挂单点位（波段核心通道下沿/多头主清算密集区）。
   - **第三级（终极恐慌踩踏底）**：定位于 `1H/4H` 宏观大级别支撑中枢。若瀑布加速下杀，实行**下砸不设限动态追踪**（紧缩保利止损直至底部出现天量长下影承接或触发保利止损）。
2. **针尖超前锁盈触发（防V反滞后）**：
   - 当持仓处于显著浮盈状态（100x 浮盈 $\ge +50\%$）时，若 `1m` K 线突然爆出 **极端天量（`vol_ratio_1m >= 4.5x`）+ 剧烈长下影线抽升（`lower_wick >= 0.60 * ATR_5m`）**，或从波段最低点极速反抽超过阈值，立即唤醒评估锁盈或收紧保利止损。

## 5. 多档位监控流转、巨鲸逐笔流触发器与定期巡检铁律 (Monitoring & Audit Cadence)

### 5.1 实时 WebSocket 多维异动触发器 (`tickers` + `trades`)
后台守护进程（`okx_ctl.py watch`）实时监听毫秒级行情与逐笔成交，满足任一条件立即打破静默唤醒 Agent：
1. **巨鲸单笔天量吃单/砸盘告警 (`WHALE_TRADE_ALERT`)**：
   - 实时监测 `trades` 逐笔成交流，当出现单笔成交张数 $\ge \text{whale\_sz}$ 时毫秒级中断唤醒：
     - **盘口贴身肉搏期**：设 `--whale-sz 300`（`30 ETH`）高频透视多空主力大单交锋与吸收效率；
     - **常规/长效趋势值守期**：设 `--whale-sz 1500` 或 `2000`（`150~200 ETH`）过滤中小型噪音，仅在机构级超级重炮轰击盘口时唤醒；
     - **定时复盘汇总期**：设 `--whale-sz 5000`（`500 ETH`），避免常规大单频繁打断，按固定周期输出汇总复盘。
2. **下拉关键阶梯/支撑破位告警 (`PROFIT_STEP_BREAKDOWN_ALERT`)**：
   - 通过 `--support <px>` 设定下方前低或关键阶梯支撑位，一旦价格向下击穿该支撑位，立即唤醒追击瀑布并执行结构化下移止损。
3. **触底快速反抽防守告警 (`CLIMAX_REBOUND_ALERT`)**：
   - 当价格处于深水浮盈区并从周期最低点（`cycle_min_px`）快速反弹达到设定阈值时，立即唤醒评估反抽力度与止盈保护。
4. **阻力突破与逼空告警 (`RESISTANCE_BREAKOUT_ALERT` / `BUY_VOLUME_SURGE_ALERT`)**：
   - 价格向上穿透 `--resistance <px>` 动态阻力线，或 20s 滚动窗口内买盘涌入 $\ge 350\text{ ETH}$ 且占比 $\ge 75\%$ 逼近阻力区时立即唤醒。
5. **目标止盈与硬损逼近告警 (`TARGET_TP_ALERT` / `STOP_LOSS_APPROACH_ALERT`)**。

### 5.2 多档位自适应监控流转体系 (`60s` / `120s` / `900s` / `7200s` + `15m Cron`)
系统采用 **“后台常驻 15m Cron 守护心跳 + 动态 WebSocket 触发器”** 双轨并驱架构，严禁空窗断连：
1. **极速肉搏/定时复盘档（`30s ~ 60s`）**：
   - 适用于瀑布破位瞬间、关键阻力攻防期、四大特殊敏感时间窗口，或用户指令下的 **1分钟定时全景复盘模式**。
2. **标准高速过渡档（`120s`）**：
   - 适用于突破/巨鲸异动后的结构观察期，或过去 10 分钟高低振幅 $> 2.5\text{ USDT}$ 的常规波动期。若 120s 周期内未触发异动且振幅收敛，向长效档位进阶。
3. **长效静默值守档（`900s / 15m` 或 `7200s / 120m`）**：
   - 当反扑确认无力、盘面进入低波动横盘蓄势，或已布好深厚保利止损等待大波段穿仓时，开启 `900s` 至 `7200s` 长效 WebSocket 守候（挂载 `--whale-sz` 与 `--support/--resistance` 触发器）。无事静默省流，遇巨鲸轰击或破位即刻毫秒级唤醒并切回 `60s/120s` 高速态。

### 5.3 四大特殊敏感时域窗口（强制极速模式）
1. **下午欧盘开盘与资金苏醒窗口（`15:00 ~ 17:00 BJ`）**：欧洲主力进场叠加 `16:00` 费率交割，强制锁定 `60s` 模式。

## 6. 原子控制工具 `okx_ctl.py` 标准接口 (CLI Reference)

```bash
# 1. 全周期结构、持仓与情绪快照 (1m/5m/15m/1H 指标 + 账户持仓)

python -u okx_ctl.py orderbook
```
